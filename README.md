# 📡 رادار خبر اقتصادی

یک سیستم کاملاً خودکار که **هر ۳۰ دقیقه** حدود ۴۷ منبع ایرانی و بین‌المللی رو می‌خونه. خبرها رو با ذهن اقتصادی، سیاسی، اجتماعی و معامله‌گری تحلیل می‌کنه و فقط خبرهایی که از فیلترها رد بشن رو با **لحن خودمونی** به تلگرام شما می‌فرسته. هر نوتیف یک پست آماده‌ی انتشار و یک پکیج اینستاگرام هم داره.

بعد از راه‌اندازی، لازم نیست هیچ دکمه‌ای بزنید. سیستم روی سرورهای GitHub اجرا میشه و کامپیوتر شما لازم نیست روشن باشه.

---

## چطور کار می‌کنه؟

```
هر ۳۰ دقیقه
   │
   ├─ ۱. جمع‌آوری ── ۱۵ کانال تلگرام + ۲۳ فید RSS + ۹ جست‌وجوی گوگل‌نیوز
   │                 + قیمت‌ها (تتر، انس، نفت، DXY، بیت‌کوین) + ارزش ذاتی طلای ۱۸ و سکه
   │                 + تقویم اقتصادی
   │
   ├─ ۲. فیلتر تازگی ── فقط خبرهای ۳ ساعت اخیر که قبلاً دیده نشدن
   │                    + یکی کردن یک خبر از چند منبع
   │
   ├─ ۳. غربال هوشمند (Claude Haiku) ── امتیاز ۰ تا ۱۰۰ بر اساس اولویت‌های کانال،
   │                    اثر روی جیب مردم، تازگی و اعتبار؛ حذف تکراری‌های ۲۴ ساعت اخیر
   │
   ├─ ۴. راستی‌آزمایی ── خبر مهمِ تک‌منبعی با جست‌وجوی وب چک میشه
   │
   ├─ ۵. تحلیل و نوشتن (Claude Sonnet) ── تحلیل چندلایه + سناریو + نگاه معامله‌گر
   │                    + پست آماده + پکیج اینستاگرام. اگه بی‌ارزش باشه، نمی‌فرسته
   │
   └─ ۶. نوتیف تلگرام
```

**کارهای زمان‌دار:**
- ☀️ **بریف صبح** ساعت ۸:۰۰ تهران، شامل خبرهای شب، قیمت‌ها و تقویم امروز.
- 🌙 **جمع‌بندی شب** ساعت ۲۱:۳۰، شامل گزارش هزینه و منابع خراب.
- 📈 **هشدار حرکت قیمت**، مثلاً وقتی تتر در نیم ساعت بیش از ۱.۵٪ تکون بخوره، همراه با حدس دلیلش از روی خبرها.
- ⏰ **یادآوری تقویم اقتصادی** یک ساعت قبل از داده‌های مهم آمریکا (تورم، اشتغال، فدرال رزرو).
- 🌙 **ساعت سکوت** (۱:۳۰ تا ۷:۰۰): فقط خبرهای «فوری» میاد و بقیه به بریف صبح منتقل میشه.

**ارزش ذاتی طلا و سکه:** سیستم از روی انس جهانی و قیمت تتر حساب می‌کنه که طلای ۱۸ و سکه «بدون حباب» چقدر می‌ارزن. هر وقت قیمت بازار در خبرها بیاد، تحلیلگر حباب رو تخمین می‌زنه. این همون نگاهیه که معامله‌گرها برای سنجش ریسک ریزش دارن.

## هر نوتیف چی داره؟

**پیام اول، کارت تحلیل:**

```
🔴 فوری · امتیاز ۹۲ · ژئوپلیتیک
تیتر

📌 چرا مهمه
🧭 زاویه‌ها: اقتصادی / سیاسی / اجتماعی
📊 اثر روی بازار: دلار ⬆️، طلا ↕️، ... (افق و میزان اطمینان)
🎲 سناریوها با احتمال
🧠 نگاه معامله‌گر: محرک بعدی، چی رو زیر نظر داشته باشیم، چی تحلیل رو باطل می‌کنه
🎬 پکیج اینستاگرام (بازشونده): قلاب ریلز، اسکریپت، کپشن، نظرسنجی استوری
🔎 اعتبار + نتیجه‌ی راستی‌آزمایی + لینک منابع
```

**پیام دوم، متن آماده‌ی انتشار:** فقط متن پست با لحن کانال. برای کپی، روی پیام نگه دارید و Copy رو بزنید. برای فوروارد بدون اسم ربات هم می‌تونید از Forward ← Hide sender name استفاده کنید.

## راه‌اندازی (حدود ۲۰ دقیقه)

### قدم ۱: ساخت ربات تلگرام
1. در تلگرام به **@BotFather** پیام بدید و `/newbot` رو بفرستید.
2. یک اسم و یک یوزرنیم بدید. یوزرنیم باید به `bot` ختم بشه.
3. BotFather یک **توکن** میده که شبیه `123456789:AAH...` است. نگهش دارید.
4. ربات خودتون رو باز کنید و `/start` بفرستید. این قدم لازمه.

> اگه می‌خواید نوتیف‌ها برای چند نفر بره: یک کانال یا گروه خصوصی بسازید، ربات رو **ادمین** کنید و یک پیام توش بفرستید. chat id این حالت با `-100` شروع میشه.

### قدم ۲: کلید Claude API
1. وارد **platform.claude.com** بشید و ثبت‌نام کنید.
2. از بخش **Billing** اعتبار بخرید. برای شروع ۲۰ دلار کافیه.
3. پیشنهاد می‌کنم یک **سقف خرج ماهانه** هم بذارید.
4. از بخش **API Keys** گزینه‌ی **Create Key** رو بزنید و کلید رو کپی کنید. کلید با `sk-ant-` شروع میشه.

### قدم ۳: ساخت مخزن (Repository) در GitHub
1. در **github.com** حساب بسازید، روی **New repository** بزنید و اسمش رو بذارید `news-radar`.
2. **Public یا Private؟**
   - **Public (پیشنهادی):** اجرای خودکار GitHub برای مخزن عمومی در حال حاضر رایگان و نامحدوده. کد و تنظیمات دیده میشه، ولی کلیدها (Secrets) **هیچ‌وقت** دیده نمی‌شن.
   - **Private:** در حال حاضر ماهانه ۲۰۰۰ دقیقه رایگان داره. اجرای هر ۳۰ دقیقه ممکنه از این سقف رد بشه. اگه خصوصی می‌خواید، در فایل `.github/workflows/radar.yml` خط cron رو به `"7 * * * *"` تغییر بدید تا ساعتی یک بار اجرا بشه.
3. **Create repository** رو بزنید.
4. در صفحه‌ی مخزن روی **uploading an existing file** بزنید.
5. **محتوای** پوشه‌ی unzip‌شده رو بکشید و رها کنید (همه‌ی فایل‌ها و پوشه‌ها، نه خود پوشه).
6. **Commit changes** رو بزنید.
7. ⚠️ **چک کنید فایل `.github/workflows/radar.yml` آپلود شده باشه.** در مک، پوشه‌هایی که با نقطه شروع میشن مخفی‌اند. با `Cmd + Shift + .` نمایششون بدید.
8. اگه هنوز نیست: **Add file ← Create new file** بزنید، اسم رو دقیقاً `.github/workflows/radar.yml` بنویسید، محتوای همون فایل رو paste کنید و Commit کنید.

### قدم ۴: اجازه‌ی ذخیره و کلیدها
1. **Settings ← Actions ← General ← Workflow permissions** رو باز کنید، گزینه‌ی **Read and write permissions** رو بزنید و **Save** کنید. سیستم حافظه‌اش (خبرهای دیده‌شده) رو در فایل `state/state.json` ذخیره می‌کنه و به این اجازه نیاز داره.
2. **Settings ← Secrets and variables ← Actions ← New repository secret** رو باز کنید و این دو تا رو بسازید:
   - `ANTHROPIC_API_KEY`: کلید قدم ۲
   - `TELEGRAM_BOT_TOKEN`: توکن قدم ۱
3. **پیدا کردن chat id:**
   1. تب **Actions** رو باز کنید و **News Radar** رو انتخاب کنید.
   2. **Run workflow** رو بزنید، دستور `chat-id` رو انتخاب کنید و Run کنید.
   3. وقتی اجرا تموم شد، روی اون اجرا بزنید و مرحله‌ی **Run radar** رو باز کنید. عدد جلوی `TELEGRAM_CHAT_ID` رو کپی کنید.
4. یک Secret سوم به اسم `TELEGRAM_CHAT_ID` با همین عدد بسازید.

### قدم ۵: تست
از تب **Actions ← News Radar ← Run workflow** این دستورها رو به ترتیب اجرا کنید:

| دستور | نتیجه‌ی مورد انتظار |
|---|---|
| `test-telegram` | پیام «✅ رادار خبر وصله!» در تلگرام |
| `check-sources` | در لاگ: ✅ یا ❌ برای هر منبع |
| `prices` | در لاگ: قیمت‌های در دسترس |
| `run` | اولین اجرای واقعی؛ نوتیف خبرهای مهم ۳ ساعت اخیر |

✅ **تمام!** از این به بعد سیستم خودش هر ۳۰ دقیقه اجرا میشه.

## شخصی‌سازی

همه‌ی تنظیمات در فایل‌های متنی‌اند. برای ویرایش، در خود GitHub روی فایل بزنید، آیکون ✏️ رو بزنید، تغییر بدید و **Commit** کنید. تغییر از اجرای بعدی اعمال میشه.

| می‌خوام... | کجا؟ |
|---|---|
| امضای کانالم آخر پست‌ها بیاد | `config/settings.yaml` ← `channel.signature` |
| پیام کمتر یا بیشتر بیاد | `filters.min_score`: بالاتر یعنی کمتر (مثلاً ۸۰)، پایین‌تر یعنی بیشتر (مثلاً ۶۵) |
| اولویت‌های محتوایی عوض بشه | `channel.focus` و `channel.avoid` |
| ساعت سکوت با ساعت خودم تنظیم بشه | `time.user_timezone` (مثلاً `Europe/Berlin`) و `quiet_hours` |
| ساعت بریف‌ها عوض بشه | `briefs.morning.time` و `briefs.evening.time` (به وقت تهران) |
| تحلیل‌ها قوی‌تر بشه | `models.writer: "claude-opus-5-5"` (حدوداً دو برابر هزینه) |
| هزینه کمتر بشه | `models.writer: "claude-haiku-5-5"` و `verification.enabled: false` |
| لحن تغییر کنه | `prompts/style.md` |
| منبع اضافه یا حذف بشه | `config/sources.yaml`: کانال تلگرام فقط با یوزرنیم اضافه میشه؛ برای حذف `enabled: false` |
| حساسیت هشدار قیمت عوض بشه | `market_alerts.thresholds_pct` |

بعد از تغییر منابع، دستور `check-sources` رو اجرا کنید. منابعی که در `sources.yaml` با ✔ علامت خوردن رو دستی چک کردم. بقیه رو اولین `check-sources` نشون میده.

## هزینه (تخمینی)

| بخش | مدل | تقریباً در ماه |
|---|---|---|
| غربال (۴۸ بار در روز) | Haiku 5.5 | ۳ تا ۵ دلار |
| تحلیل و نوشتن (حدود ۲۰ نوتیف در روز) | Sonnet 5.5 | ۱۵ تا ۲۵ دلار |
| راستی‌آزمایی با جست‌وجوی وب | Haiku 5.5 + جست‌وجو | ۳ تا ۶ دلار |
| بریف صبح و شب + هشدار قیمت | Sonnet 5.5 | ۲ تا ۴ دلار |
| GitHub Actions (مخزن عمومی) | — | رایگان |
| **جمع** | | **حدود ۲۵ تا ۴۰ دلار** |

- این عددها بر اساس قیمت‌های فعلی API و فرض حدود ۲۰ نوتیف در روزه. متن فارسی توکن بیشتری مصرف می‌کنه، پس عدد واقعی ممکنه فرق کنه.
- هزینه‌ی واقعی هر روز در **جمع‌بندی شب** گزارش میشه.
- حالت اقتصادی (Haiku برای نوشتن، بدون راستی‌آزمایی) حدود ۸ تا ۱۲ دلار در ماهه.
- با Opus برای نوشتن، حدود ۴۵ تا ۶۵ دلار در ماهه.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| هیچ پیامی نمیاد | تب Actions ← آخرین اجرا ← لاگ رو ببینید. `test-telegram` رو اجرا کنید. Secrets رو چک کنید. |
| خطای `401` یا `credit balance` | کلید API یا اعتبار حساب در platform.claude.com |
| خطای `403` موقع Save state | قدم ۴.۱ (Read and write permissions) |
| یک منبع ❌ است | یا یوزرنیم یا آدرس عوض شده، یا سایت سرورهای GitHub رو می‌بنده. اصلاحش کنید یا `enabled: false` بذارید. سیستم با بقیه‌ی منابع کار می‌کنه. |
| قیمت تتر نمیاد (دستور `prices`) | نوبیتکس و والکس ممکنه دسترسی از سرورهای خارج رو ببندن. سیستم بدون اون‌ها هم کار می‌کنه و قیمت دلار و طلا رو از خبرها می‌خونه؛ فقط هشدار حرکت تتر و «ارزش ذاتی» حذف میشه. |
| اجراها چند دقیقه دیر شروع میشن | زمان‌بندی GitHub در ساعت‌های شلوغ ۵ تا ۲۰ دقیقه تأخیر داره؛ طبیعیه. |
| بعد از مدت طولانی اجرا متوقف شد | GitHub زمان‌بندی مخزن‌های بی‌فعالیت رو بعد از ۶۰ روز خاموش می‌کنه. ذخیره‌ی خودکار state معمولاً جلوی این رو می‌گیره. اگه پیش اومد، از تب Actions دوباره Enable کنید. |

## اجرا روی سرور یا کامپیوتر شخصی (اختیاری، به‌جای GitHub)

```bash
cd news-radar
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # سه مقدار رو داخلش پر کنید
python -m radar test-telegram
python -m radar run

# اجرای خودکار هر ۳۰ دقیقه:  crontab -e  و این خط:
7,37 * * * * cd /path/to/news-radar && .venv/bin/python -m radar run >> radar.log 2>&1
```

**تست بدون هزینه و بدون ارسال:**

```bash
python -m radar run --dry-run --mock-llm
pip install pytest && python -m pytest -q
```

## نکته‌های مهم

- **این سیستم دستیار سردبیره، نه جایگزین شما.** مدل ممکنه اشتباه کنه. قبل از انتشار، عددها و ادعاهای حساس رو یک نگاه سریع بندازید. لینک منابع و نتیجه‌ی راستی‌آزمایی برای همین در هر کارت هست.
- **پیش‌بینی‌ها سناریو هستن، نه سیگنال خرید و فروش.** پرامپت‌ها عمداً طوری نوشته شدن که توصیه‌ی شخصی ندن.
- **کانال‌های رقیب** فقط برای تشخیص ترند خونده میشن و متن‌شون کپی نمیشه.
- **X (توییتر)** مستقیم خونده نمیشه چون API رایگان نداره. کانال تلگرام FinancialJuice که تیترهای لحظه‌ای بازار (از جمله نقل از X) رو منتشر می‌کنه این جای خالی رو تا حدی پر می‌کنه.
- **اینستاگرام** خودکار پست نمی‌ذاره. سیستم فقط محتوای آماده رو تحویل میده و انتشار با خودتونه.
